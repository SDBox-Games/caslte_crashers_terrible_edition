Drop PNG, JPG, JPEG, WEBP, or BMP pictures here to add them to the main menu.

Pictures are scaled to fill the screen, sorted by filename, changed automatically,
and crossfaded. A 16:9 image such as 1280x720 or 1920x1080 works best.

Run `py generate_assets.py` from the game folder to restore the three included
original menu scenes.
