# Lava World art

These PNG files are the editable artwork used by Lava World at runtime. You can repaint any file directly; restart the game to reload it.

`tools/generate_lava_world_art.py` recreates the complete default set with Pillow. Running that script overwrites the PNGs in this folder, so do not run it after repainting files unless you want to restore the generated defaults.

Animated lava, fire, magic, fades, hit markers, health bars, and particles remain runtime effects. Static scenery, bosses, props, signs, boulders, and both finale locations are PNG assets here.
