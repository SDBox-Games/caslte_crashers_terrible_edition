Place optional music files in this folder. The game detects them when it starts.

Supported names:
  main_menu.mp3   Main menu and character selection
  map.mp3         World map
  arena.mp3       Arena (falls back to map.mp3)
  blacksmith.mp3  Blacksmith, Pet House, and Weapon Frog (falls back to map.mp3)
  frog.mp3        Legacy Frog music name
  home_castle.mp3 Home Castle (falls back to map.mp3)

OGG and WAV files with the same base names are also supported. Missing songs do
not stop the game, and switching screens changes music without blocking gameplay.
